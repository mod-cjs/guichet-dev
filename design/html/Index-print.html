Principes

Mobile first, dense, rapide
Pas de webfont. Texte de base 13px. Pensé pour les réseaux sénégalais.
Tutoiement, voix locale
« Trouver ma prochaine opp », pas « Découvrez ». FCFA, régions, prénoms.
Trait 1.5px, pas d'ombre
Les cartes posées dans la page utilisent un trait, pas d'ombre. L'ombre = flottant.
Couleurs = sémantique
Jaune = action / today. Bleu, vert, rouge = statuts uniquement. Indigo = chatbot.
Emoji réservés
Un jeu fixe (🎓 🚀 🤝 📚 🌾 📍 📅 …). Pas de bibliothèque d'icônes tierce.
Programmes par leur nom
Yaakaar, YEAH, YJC, BRM, e-learning. C'est l'ADN de la plateforme.
